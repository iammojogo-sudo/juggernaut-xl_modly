# Juggernaut XL for Modly

Photorealism-focused SDXL model for image generation, editing, and inpainting.

## Features
- **Generate Image** — text-to-image with pose/camera control, upscaling
- **img2img** — edit existing images with prompt guidance
- **Inpaint** — replace masked areas (background, objects)

## Installation
Modly → Extensions → Install from GitHub → paste repo URL

## VRAM
Minimum 6GB (8GB+ recommended)
